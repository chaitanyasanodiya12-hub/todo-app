# To-Do List App

A simple to-do list built with HTML, CSS and JavaScript.

## Features
- Add tasks (button or Enter key)
- Bullet pointer and checkbox on every task
- Tick a task to mark it done
- Delete tasks
- Tasks are saved in the browser (localStorage)

## Run
Open `index.html` in any browser.
